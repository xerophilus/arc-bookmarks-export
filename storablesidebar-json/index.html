What is StorableSidebar.json?

StorableSidebar.json is Arc browser's internal database file that stores your complete sidebar structure — every Space, pinned tab, unpinned tab, folder, subfolder, and Favorite, including metadata like colors, icons, and timestamps.

It's the most complete representation of your Arc browsing setup, far more detailed than Arc's official Markdown export.

What's Inside StorableSidebar.json?

  • ✅ All your Spaces (the colored containers in Arc's sidebar)
  • ✅ Pinned tabs in each Space
  • ✅ Unpinned "Today" tabs
  • ✅ Nested folders and their complete hierarchy
  • ✅ Favorites (the pinned items at the top of your sidebar)
  • ✅ Split Views (grouped tabs)
  • ✅ Metadata: colors, custom names, creation dates, URLs

This file is stored locally on your computer and synced between devices if you use Arc's sync feature.

Where to Find StorableSidebar.json

⚠️ Important: Quit Arc completely before accessing this file. Arc locks the file while running, and copying it while Arc is open may result in a corrupted or incomplete backup.

On Mac

  1. Quit Arc (Cmd+Q or Arc menu → Quit Arc)
  2. Open Finder
  3. Click Go in the menu bar
  4. Select Go to Folder… (or press Shift+Cmd+G)
  5. Paste this path: ~/Library/Application Support/Arc/
  6. Press Go
  7. You'll see StorableSidebar.json in the folder

On Windows

  1. Close Arc completely
  2. Press Win+R to open the Run dialog
  3. Type: %LOCALAPPDATA%\Packages\ and press Enter
  4. Find the folder that starts with TheBrowserCompany.Arc (full name is something like TheBrowserCompany.Arc_tq3kkv497wwe)
  5. Open that folder, then navigate to: LocalCache\Local\Arc\
  6. You'll find StorableSidebar.json there

How to Back Up StorableSidebar.json

  1. Quit Arc completely (very important!)
  2. Navigate to the file location using the instructions above
  3. Right-click StorableSidebar.json
  4. Select Copy (Mac) or Copy (Windows)
  5. Paste it somewhere safe:
    • Your Desktop
    • A Documents folder
    • Cloud storage (Dropbox, Google Drive, iCloud, etc.)
    • An external USB drive
  6. Rename the copy to something like StorableSidebar-backup-2026-10-22.json so you remember when you saved it
⚠️ Back up before December 22, 2026! Arc stops working on that date. After Arc shuts down, you may still be able to access this file, but it's safer to back it up now while Arc is still running.

Can I Edit StorableSidebar.json Manually?

Not recommended. While it's a JSON text file and technically editable, Arc expects a specific structure with IDs, timestamps, and relationships between items. Manual edits can corrupt your sidebar or cause Arc to crash.

If you want to convert it to a standard bookmarks file that works in Chrome, Firefox, Safari, or other browsers, use the Arc Bookmarks Converter.

StorableSidebar.json vs Arc's Markdown Export

StorableSidebar.json Markdown Export
Spaces ✅ Preserved ✅ Preserved (as headings)
Pinned tabs ✅ All included ⚠️ Only some included
Folders ✅ Fully nested ✅ As indented lists
Favorites ✅ Yes ❌ No
Metadata ✅ Colors, icons, dates ❌ None
Ease of access ⚠️ Hidden system file ✅ File → Export Data

Recommendation: Use StorableSidebar.json if you want the most complete backup. Use the Markdown export if you only need a quick list of links.
