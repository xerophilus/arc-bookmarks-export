What is StorableSidebar.json?

StorableSidebar.json is Arc's internal file that stores your complete sidebar — every Space, pinned tab, folder, and Favorite, including metadata like colors and timestamps.

It's the most complete representation of your Arc setup, far more detailed than Arc's Markdown export.

What's inside

  • All your Spaces
  • Pinned tabs in each Space
  • Unpinned "Today" tabs
  • Nested folders and their hierarchy
  • Favorites (pinned items at top)
  • Split Views (grouped tabs)
  • Metadata: colors, names, dates, URLs

The file is stored locally and synced between devices if you use Arc's sync.

Where to find it

Important: Quit Arc before accessing this file. Arc locks it while running. Copying while Arc is open may result in corruption.

On Mac

  1. Quit Arc (Cmd+Q)
  2. Open Finder
  3. Click Go in menu bar
  4. Select Go to Folder… (Shift+Cmd+G)
  5. Paste: ~/Library/Application Support/Arc/
  6. Press Go
  7. You'll see StorableSidebar.json

On Windows

  1. Close Arc
  2. Press Win+R
  3. Type: %LOCALAPPDATA%\Packages\
  4. Find folder starting with TheBrowserCompany.Arc
  5. Open it, then: LocalCache\Local\Arc\
  6. You'll find StorableSidebar.json

How to back it up

  1. Quit Arc completely
  2. Navigate to the file using instructions above
  3. Right-click StorableSidebar.json
  4. Select Copy
  5. Paste somewhere safe: Desktop, Documents, cloud storage, USB drive
  6. Rename the copy: StorableSidebar-backup-2026-10-22.json
Back up before December 22, 2026. Arc stops working on that date. After shutdown you may still access this file, but it's safer to back up now.

Can I edit it manually?

Not recommended. While it's a JSON text file, Arc expects a specific structure with IDs, timestamps, and relationships. Manual edits can corrupt your sidebar or crash Arc.

StorableSidebar.json vs Markdown export

StorableSidebar.json Markdown Export
Spaces Preserved Preserved (as headings)
Pinned tabs All included Only some
Folders Fully nested Indented lists
Favorites Yes No
Metadata Colors, icons, dates None
Access Hidden system file File → Export Data

Recommendation: Use StorableSidebar.json for the most complete backup. Use Markdown export if you only need a quick list of links.
