How to Export Arc Bookmarks to Zen Browser

Zen Browser is a beautifully designed, privacy-focused browser built on Firefox. It's a popular choice for Arc users looking for a similar modern aesthetic with vertical tabs and customizable workspaces. Here's how to migrate your Arc bookmarks before the December 22, 2026 shutdown.

Step-by-Step Instructions

1. Get Your Arc Data

Option A: StorableSidebar.json (Recommended)

  1. Close Arc completely
  2. On Mac: Finder → Go → Go to Folder… → paste ~/Library/Application Support/Arc/
  3. On Windows: Press Win+R → type %LOCALAPPDATA%\Packages\ → find the folder starting with TheBrowserCompany.Arc → navigate to LocalCache\Local\Arc\
  4. Copy StorableSidebar.json to a safe location

Option B: Arc's Markdown Export

  1. In Arc: File → Export Data (see Arc's export guide)
  2. Save Arc Data Export.md

2. Convert to Zen-Compatible Format

  1. Visit the Arc Bookmarks Converter
  2. Drop your Arc export file onto the converter
  3. Preview your bookmark tree to confirm everything is correct
  4. Unlock the download for $7 and download bookmarks.html

3. Import into Zen Browser

  1. Open Zen Browser
  2. Press Ctrl+Shift+O (Windows/Linux) or Cmd+Shift+O (Mac) to open the Library
  3. Click Import and Backup in the toolbar
  4. Select Import Bookmarks from HTML…
  5. Choose your bookmarks.html file
  6. Click Open

Your Arc Spaces will appear as organized folders under "Arc Import" in Zen's bookmarks system. You can then organize them into Zen's workspace feature.

What Transfers to Zen?

  • ✅ All Spaces (as bookmark folders)
  • ✅ Pinned tabs
  • ✅ Nested folders and hierarchies
  • ✅ Favorites
  • ✅ Unpinned "Today" tabs
  • ✅ Split View collections

Why Zen for Arc Users?

Many Arc users are switching to Zen because it offers:

  • 🎨 Clean, modern interface similar to Arc's aesthetic
  • 📱 Vertical tabs and sidebar navigation
  • 🔒 Privacy-first (built on Firefox)
  • 🆓 Completely free and open source
  • ⚙️ Highly customizable workspaces

Zen uses Firefox's import system, which means it can't directly read Arc's Markdown export — that's where this converter helps.

If you want a free Arc migration tool, Dia (The Browser Company's new browser) includes Arc import built-in.
