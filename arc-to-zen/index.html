Export Arc bookmarks to Zen Browser

Zen is a modern, privacy-focused browser built on Firefox. It's popular with Arc users for its clean design, vertical tabs, and customizable workspaces. Here's how to migrate your bookmarks before Arc shuts down December 22, 2026.

Step 1: Get your Arc data

Option A: StorableSidebar.json (recommended)

  1. Close Arc
  2. Mac: Finder → Go → Go to Folder → ~/Library/Application Support/Arc/
  3. Windows: Win+R → %LOCALAPPDATA%\Packages\ → folder starting with TheBrowserCompany.Arc → LocalCache\Local\Arc\
  4. Copy StorableSidebar.json

Option B: Markdown export

  1. Arc → File → Export Data
  2. Save Arc Data Export.md

Step 2: Convert

  1. Visit the converter
  2. Drop your file
  3. Preview your bookmark tree
  4. Pay $7, download bookmarks.html

Step 3: Import to Zen

  1. Open Zen Browser
  2. Press Ctrl+Shift+O (Windows/Linux) or Cmd+Shift+O (Mac)
  3. Click Import and Backup
  4. Select Import Bookmarks from HTML…
  5. Choose bookmarks.html
  6. Click Open

Your Spaces appear as folders under "Arc Import". You can organize them into Zen's workspaces.

What transfers

  • All Spaces (as folders)
  • Pinned tabs
  • Nested folders
  • Favorites
  • Unpinned tabs
  • Split Views

Why Zen for Arc users

Many Arc users like Zen because it has:

  • Clean, modern interface (similar to Arc)
  • Vertical tabs and sidebar navigation
  • Privacy-first (Firefox-based)
  • Free and open source
  • Customizable workspaces

Zen uses Firefox's import system, so it can't read Arc's Markdown export directly — that's where this converter helps.

Free alternative: Dia (The Browser Company's new browser) includes Arc import.
