Export Arc bookmarks to Safari

Safari is Apple's browser for Mac, iPhone, and iPad. Here's how to bring your Arc Spaces, tabs, and folders into Safari before Arc shuts down in December 2026.

Step 1: Get your Arc data

Option A: StorableSidebar.json (full structure)

  1. Quit Arc
  2. Mac: Finder → Go → Go to Folder → ~/Library/Application Support/Arc/
  3. Copy StorableSidebar.json to Desktop

Option B: Arc's export

  1. Arc → File → Export Data
  2. Save Arc Data Export.md

Step 2: Convert

  1. Open the converter
  2. Drop your file
  3. Check the preview
  4. Pay $7, download bookmarks.html

Step 3: Import to Safari

  1. Open Safari
  2. Click File in the menu bar
  3. Select Import From → Bookmarks HTML File…
  4. Choose bookmarks.html
  5. Click Import

Your Arc bookmarks appear in a folder called "Imported". Each Space becomes a subfolder.

What migrates

  • All Spaces (as folders)
  • Pinned tabs
  • Nested folders
  • Favorites
  • Unpinned tabs
  • Split Views

Safari doesn't support Arc's color coding or custom icons — those are visual features unique to Arc.

Safari's import vs. this tool

Safari can import from Chrome, Firefox, and other browsers via File → Import From. But Safari can't import Arc's Markdown export because Arc doesn't use standard bookmarks format.

Free option: Dia (The Browser Company's new browser) includes Arc import.
