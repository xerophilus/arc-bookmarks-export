How to Export Arc Bookmarks to Safari

Safari is Apple's native browser for Mac, iPhone, and iPad. If you're switching from Arc before it shuts down in December 2026, here's how to bring your Spaces, pinned tabs, and folder structure into Safari.

Step-by-Step Instructions

1. Get Your Arc Data

Option A: StorableSidebar.json (Preserves full structure)

  1. Quit Arc
  2. On Mac: Open Finder → Go menu → Go to Folder… → type ~/Library/Application Support/Arc/
  3. Find StorableSidebar.json and copy it to your Desktop

Option B: Use Arc's Export Feature

  1. In Arc, go to File → Export Data
  2. Save the Arc Data Export.md file

2. Convert to Safari-Compatible HTML

  1. Open the Arc Bookmarks Converter
  2. Drag your file (StorableSidebar.json or Arc Data Export.md) onto the page
  3. Check the free preview to ensure all your bookmarks were detected
  4. Unlock the download for $7 and save bookmarks.html

3. Import into Safari

  1. Open Safari on your Mac
  2. Click File in the menu bar
  3. Select Import From → Bookmarks HTML File…
  4. Choose your downloaded bookmarks.html
  5. Click Import

Your Arc bookmarks will appear in a new folder called "Imported" in Safari's bookmarks. Each of your Arc Spaces becomes a subfolder.

What Migrates to Safari?

  • ✅ All Spaces (as organized folders)
  • ✅ Pinned tabs
  • ✅ Nested folder structures
  • ✅ Favorites
  • ✅ Unpinned tabs from "Today"
  • ✅ Split Views

Note: Safari doesn't support Arc's color coding or custom icons — those are visual features unique to Arc.

Safari's Native Import vs. This Tool

Safari can import bookmarks from Chrome, Firefox, and other standard browsers using File → Import From. However, Safari cannot import Arc's Markdown export because Arc doesn't use the standard bookmarks format.

This converter bridges that gap by transforming Arc's data into the universal Netscape HTML format that Safari (and every other browser) understands.
