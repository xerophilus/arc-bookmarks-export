Export Arc bookmarks to Firefox

Firefox is privacy-focused and open-source. Here's how to bring your Arc sidebar — Spaces, folders, everything — into Firefox before Arc shuts down December 22, 2026.

Step 1: Get your Arc data

Option A: StorableSidebar.json (best for structure)

  1. Close Arc
  2. Mac: Finder → Go → Go to Folder → ~/Library/Application Support/Arc/
  3. Windows: Win+R → %LOCALAPPDATA%\Packages\ → folder starting with TheBrowserCompany.Arc → LocalCache\Local\Arc\
  4. Copy StorableSidebar.json

Option B: Arc's export

  1. In Arc: File → Export Data
  2. Save Arc Data Export.md

Step 2: Convert

  1. Go to the converter
  2. Drop your file
  3. Preview to verify
  4. Pay $7 and download bookmarks.html

Step 3: Import to Firefox

  1. Open Firefox
  2. Press Ctrl+Shift+O (Windows/Linux) or Cmd+Shift+O (Mac)
  3. Click Import and Backup
  4. Select Import Bookmarks from HTML…
  5. Choose bookmarks.html
  6. Click Open

All your Spaces appear as folders under "Arc Import" in Firefox bookmarks.

What transfers

  • All Spaces (each becomes a folder)
  • Pinned tabs
  • Nested folders
  • Favorites
  • Unpinned tabs
  • Split Views

Why not Firefox's built-in import?

Firefox can import from Chrome, Safari, and Edge, but not Arc. Arc only exports Markdown, not standard HTML bookmarks.

For a free option, try Dia (The Browser Company's new browser with built-in Arc import).
