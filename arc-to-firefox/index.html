How to Export Arc Bookmarks to Firefox

Firefox is a privacy-focused, open-source alternative to Chrome. If you're leaving Arc before it shuts down on December 22, 2026, this guide will help you bring your entire sidebar structure — Spaces, folders, and all — into Firefox.

Step-by-Step Instructions

1. Get Your Arc Data

Option A: StorableSidebar.json (Best for preserving structure)

  1. Close Arc completely
  2. On Mac: Finder → Go → Go to Folder… → enter ~/Library/Application Support/Arc/ and press Go
  3. On Windows: Press Win+R → type %LOCALAPPDATA%\Packages\ → open the folder beginning with TheBrowserCompany.Arc → navigate to LocalCache\Local\Arc\
  4. Copy StorableSidebar.json somewhere safe (like your Desktop)

Option B: Arc's Official Export

  1. In Arc: File → Export Data
  2. Save Arc Data Export.md

2. Convert to Firefox-Compatible Format

  1. Visit the Arc Bookmarks Converter
  2. Drop your file (JSON or Markdown) onto the converter
  3. Review the free preview to verify your bookmarks parsed correctly
  4. Pay $7 to unlock the download and save bookmarks.html

3. Import to Firefox

  1. Open Firefox
  2. Press Ctrl+Shift+O (Windows/Linux) or Cmd+Shift+O (Mac) to open the Library
  3. Click Import and Backup at the top
  4. Select Import Bookmarks from HTML…
  5. Choose your downloaded bookmarks.html file
  6. Click Open

All your Arc Spaces will appear as organized folders under "Arc Import" in Firefox's bookmarks menu.

What Transfers to Firefox?

  • ✅ All Spaces (each becomes a folder)
  • ✅ Pinned tabs with their URLs
  • ✅ Nested folder hierarchies
  • ✅ Favorites
  • ✅ Unpinned tabs from your "Today" section
  • ✅ Split View tabs (grouped in small folders)

Why Not Use Firefox's Built-In Import?

Firefox has a great built-in importer for Chrome, Safari, Edge, and other browsers. Unfortunately, it can't read Arc's export format because Arc only exports Markdown lists, not the standard HTML bookmarks format.

If you're looking for a free alternative, Dia (The Browser Company's new browser) includes Arc import functionality at no cost.
