Where to find your Arc data

Best: StorableSidebar.json (keeps Spaces, pinned tabs, folders, Favorites). Quit Arc first, then:

  • Mac: Finder → Go → Go to Folder… → ~/Library/Application Support/Arc/ → StorableSidebar.json
  • Windows: press Win+R and open %LOCALAPPDATA%\Packages\, then the folder starting with TheBrowserCompany.Arc → LocalCache\Local\Arc\StorableSidebar.json

Alternative: Arc's Markdown export (Arc Data Export.md) — see Arc's guide How do I export my data from Arc. Headings and indented lists become folders.

How to import into your new browser

Google Chrome

Menu ⋮ → Bookmarks and lists → Import bookmarks and settings → choose Bookmarks HTML File → Choose File → select bookmarks.html.

Mozilla Firefox

Ctrl/Cmd+Shift+O (Library) → Import and Backup → Import Bookmarks from HTML… → select the file.

Safari (Mac)

File → Import From → Bookmarks HTML File… → select the file. Bookmarks appear in a folder named "Imported".

Microsoft Edge

Settings → Profiles → Import browser data → Import from: Favorites or bookmarks HTML file → Choose file.

Brave

Menu ☰ → Bookmarks → Import bookmarks and settings → Bookmarks HTML File → Choose file.

Zen Browser

Zen is Firefox-based: Ctrl/Cmd+Shift+O → Import and Backup → Import Bookmarks from HTML…

Everything is placed under a single "Arc Import" folder, with each Space as a subfolder, so nothing collides with your existing bookmarks.

FAQ

Is my data uploaded anywhere?

No. The converter is a static page; your file is read with the browser's FileReader API and converted in memory. You can even load the page, disconnect from the internet, and it still works.

What's included?

Every Space (as a top-level folder), pinned tabs, nested folders, Favorites, and unpinned "Today" tabs (in their own subfolder). Split Views become small folders.

Why not just use Arc's export?

Arc exports a Markdown file of links that browsers can't import. This tool converts it (or the richer sidebar file) into the universal Netscape bookmarks HTML format.
