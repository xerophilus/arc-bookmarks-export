Where to find your Arc data

Best: StorableSidebar.json (keeps Spaces, pinned tabs, folders, Favorites)

Quit Arc first, then:

  • Mac: Finder → Go → Go to Folder → ~/Library/Application Support/Arc/
  • Windows: Win+R, open %LOCALAPPDATA%\Packages\, find folder starting with TheBrowserCompany.Arc, then LocalCache\Local\Arc\StorableSidebar.json

Alternative: Arc's Markdown export — In Arc: File → Export Data. See Arc's guide.

More details: StorableSidebar.json explained

Import to your new browser

Chrome

Menu (⋮) → Bookmarks and lists → Import bookmarks and settings → choose Bookmarks HTML File → select bookmarks.html

Firefox

Ctrl/Cmd+Shift+O → Import and Backup → Import Bookmarks from HTML → select the file

Safari (Mac)

File → Import From → Bookmarks HTML File → select the file

Edge

Settings → Profiles → Import browser data → Favorites or bookmarks HTML file

Brave

Menu (☰) → Bookmarks → Import bookmarks and settings → Bookmarks HTML File

Zen Browser

Ctrl/Cmd+Shift+O → Import and Backup → Import Bookmarks from HTML

Detailed guides: Chrome · Firefox · Safari · Zen

Questions

  • Is my data uploaded? No. The converter is a static page. Your file is read with the browser FileReader API and converted in memory. You can load the page, disconnect from the internet, and it still works.
  • What's included? Every Space (as a folder), pinned tabs, nested folders, Favorites, and unpinned tabs. Split Views become small folders.
  • Why not use Arc's export? Arc exports a Markdown list that browsers can't import. This converts it into the standard Netscape HTML format.
