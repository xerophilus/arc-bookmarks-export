How to Export Arc Bookmarks to Chrome

Google Chrome is the most popular browser, but it can't import Arc's Markdown export directly. This guide shows you how to convert your Arc sidebar — including Spaces, pinned tabs, and nested folders — into Chrome's bookmarks format.

Step-by-Step Instructions

1. Get Your Arc Data

Option A: StorableSidebar.json (Recommended)

  1. Quit Arc completely
  2. On Mac: Open Finder → Go → Go to Folder… → paste ~/Library/Application Support/Arc/
  3. On Windows: Press Win+R → type %LOCALAPPDATA%\Packages\ → find the folder starting with TheBrowserCompany.Arc → open LocalCache\Local\Arc\
  4. Find and copy StorableSidebar.json to your Desktop

Option B: Arc's Markdown Export

  1. In Arc, click File → Export Data (or see Arc's guide)
  2. Save the Arc Data Export.md file

2. Convert to Chrome Format

  1. Go to the Arc Bookmarks Converter
  2. Drag and drop your file (StorableSidebar.json or Arc Data Export.md)
  3. Preview your bookmarks to confirm everything looks correct
  4. Unlock the download for $7 and download bookmarks.html

3. Import to Chrome

  1. Open Chrome
  2. Click the three-dot menu (⋮) in the top-right
  3. Go to Bookmarks and lists → Import bookmarks and settings
  4. Select Bookmarks HTML File from the dropdown
  5. Click Choose File and select your downloaded bookmarks.html
  6. Click Done

Your Arc Spaces will appear as folders under a new "Arc Import" folder in Chrome's bookmarks bar or bookmarks manager (Ctrl/Cmd+Shift+O).

What Gets Converted?

  • ✅ All Spaces (as top-level folders)
  • ✅ Pinned tabs
  • ✅ Nested folders and subfolders
  • ✅ Favorites
  • ✅ Unpinned "Today" tabs
  • ✅ Split Views (as small folders)

Chrome Has Built-In Import Too

Chrome can import from other browsers like Firefox, Safari, and Edge using its built-in importer. However, it cannot import Arc's format directly — Arc exports Markdown files that Chrome doesn't recognize. That's where this converter helps.

Some newer browsers like Dia (Arc's spiritual successor from The Browser Company) include Arc import built-in at no cost.
