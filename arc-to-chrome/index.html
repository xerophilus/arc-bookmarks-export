Export Arc bookmarks to Chrome

Chrome can't import Arc's Markdown export. Here's how to convert your Arc sidebar — Spaces, tabs, folders — into Chrome's bookmarks format.

Step 1: Get your Arc data

Option A: StorableSidebar.json (recommended)

  1. Quit Arc completely
  2. Mac: Finder → Go → Go to Folder → paste ~/Library/Application Support/Arc/
  3. Windows: Win+R → type %LOCALAPPDATA%\Packages\ → find folder starting with TheBrowserCompany.Arc → open LocalCache\Local\Arc\
  4. Copy StorableSidebar.json to your Desktop

Option B: Arc's Markdown export

  1. In Arc: File → Export Data
  2. Save Arc Data Export.md

Step 2: Convert to Chrome format

  1. Go to the converter
  2. Drop your file (StorableSidebar.json or Arc Data Export.md)
  3. Preview your bookmarks
  4. Pay $7 and download bookmarks.html

Step 3: Import to Chrome

  1. Open Chrome
  2. Click the three-dot menu (⋮) top-right
  3. Go to Bookmarks and lists → Import bookmarks and settings
  4. Select Bookmarks HTML File
  5. Click Choose File and select bookmarks.html
  6. Click Done

Your Arc Spaces appear as folders under "Arc Import" in Chrome's bookmarks (Ctrl/Cmd+Shift+O).

What gets converted

  • All Spaces (as folders)
  • Pinned tabs
  • Nested folders
  • Favorites
  • Unpinned tabs
  • Split Views (as folders)

Free alternatives

Chrome has built-in import from Firefox, Safari, and Edge, but not from Arc. Arc's export is Markdown, which Chrome doesn't recognize.
